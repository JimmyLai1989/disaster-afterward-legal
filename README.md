# Disaster Afterward Legal

Official public legal pages for Disaster Afterward.

## Published URLs

- Legal center: https://jimmylai1989.github.io/disaster-afterward-legal/
- Privacy Policy: https://jimmylai1989.github.io/disaster-afterward-legal/privacy/
- Terms of Use: https://jimmylai1989.github.io/disaster-afterward-legal/terms/

The site is a static GitHub Pages project in the same ten languages supported by
the game: English, Japanese, Simplified Chinese, Traditional Chinese, Korean,
French, German, Spanish, Brazilian Portuguese, and Russian. It uses no external
assets, cookies, local-storage tracking, or analytics scripts.

## GitHub Pages

Repository settings should use:

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

The repository is public so GitHub Pages can serve the documents. Public access
does not grant write access; only the owner and authorized collaborators can
modify the source.

## Release checklist

Before each store release, compare the final app build with these pages and the
Apple App Privacy / Google Play Data safety declarations. Update all three
together if any data flow changes.

Re-review this site before enabling any of the following:

- analytics, crash reporting, advertising, attribution, or push notifications;
- a developer-operated player account, backend, or cloud-save service;
- server-side purchase validation;
- subscriptions, consumable items, or paid randomized content;
- user-generated content, chat, multiplayer, friends, rankings, or achievements.

The current contact method is GitHub Issues because no public support email was
confirmed. Issues are public. Replace that method with a dedicated support or
privacy email before store submission if available.

These webpages are general Terms of Use, not a custom Apple EULA. Unless the App
Store listing provides a valid custom EULA, Apple's Standard EULA applies to the
iOS application license. A custom Apple EULA requires additional developer
identity and contact details.

Legal text should be reviewed by qualified counsel for the publisher's actual
jurisdiction, audience, age rating, and final product behavior.
